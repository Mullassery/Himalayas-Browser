📌 Key Differentiator: Form Factors

Himalayas is the only browser built for three independent form factors:

  • Desktop: Security-first (17 policies), agent-native, zero-trust
  • Mobile: Battery-first (94% idle retention), ~40-60MB footprint
  • IoT Edge: Sensor fusion, fleet management, ROS 2 native, headless-only

Competitors: Mainstream browsers are desktop→mobile ports. None support IoT or agent-native orchestration.

⚠️ Mainstream Browsers' Privacy Problem

Mainstream browsers load 100% of tracking pixels, store all user data, and sync to the vendor's cloud by default. Privacy is opt-in, not default. Score: 55/100 (lowest security, lowest privacy).
